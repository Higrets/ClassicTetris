# Классический Тетрис на Python

Игра на `pygame`: поле 10×20, все 7 классических фигур (I, O, T, S, Z, J, L),
7-bag генератор, wall kicks, «призрак» фигуры, hold, soft/hard drop,
уровни с классической таблицей скорости падения (как в NES), подсчёт очков.

## Установка и запуск

```bash
pip install pygame
python tetris.py
```

## Управление

| Клавиша            | Действие                      |
|--------------------|-------------------------------|
| ← → (или A/D)      | Движение влево/вправо         |
| ↓ (или S)          | Мягкое падение (soft drop)    |
| Пробел             | Жёсткое падение (hard drop)   |
| ↑ или X            | Поворот по часовой стрелке    |
| Z                  | Поворот против часовой        |
| C                  | Удержание фигуры (hold)       |
| P                  | Пауза                         |
| R                  | Рестарт после Game Over       |
| Esc                | Выход                         |

## Очки

- 1 линия — 100, 2 — 300, 3 — 500, 4 (Tetris) — 800 × (уровень + 1)
- Hard drop: +2 за клетку, каждые 10 снятых линий — новый уровень (падение быстрее)
