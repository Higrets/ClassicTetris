# Классический Тетрис на Python — Neon Edition

Игра на `pygame`: поле 10×20, все 7 классических фигур (I, O, T, S, Z, J, L),
7-bag генератор, wall kicks, «призрак» фигуры, hold, soft/hard drop,
уровни с классической таблицей скорости падения (как в NES), подсчёт очков,
**красивое главное меню и пакет визуальных эффектов**.

## Установка и запуск

```bash
pip install pygame
python tetris.py
```

## Экраны и визуальные эффекты

### Главное меню
- Анимированный космический фон: вертикальный градиент, дрейфующие
  «туманности» (аддитивное свечение), мерцающие звёзды, падающие
  вращающиеся фигуры-декорации.
- Неоновый заголовок «ТЕТРИС»: побуквенная бегущая радуга (HSV),
  синусоидальная волна и glow-ореол у каждой буквы; переливающийся подзаголовок.
- Кнопки (ИГРАТЬ / РЕКОРДЫ / УПРАВЛЕНИЕ / ВЫХОД): плавная анимация наведения —
  расширение, неоновая рамка, halo-свечение, маркер-треугольник; выбор мышью
  или стрелками, Enter/клик — открыть.
- Fade-in затемнение при каждом входе в меню.
- «РЕКОРДЫ» — топ-5 результатов (файл `highscores.txt`), «УПРАВЛЕНИЕ» — шпаргалка.

### Игра
- Глянцевые объёмные блоки (светлая грань + блик), glow-рамка поля,
  пульсирующая «линия отрыва» у низа.
- Переливающийся призрак фигуры, pop-in появление новых фигур.
- Сбор линий: залп частиц по всей линии + ударная волна + тряска экрана,
  всплывающие надписи («+1 ЛИНИЯ», «КВАДРИС!!», «УРОВЕНЬ N»).
- Hard drop: шлейф-силуэт по траектории, вспышка-подсветка приземления,
  тряска пропорционально высоте сброса.
- Пауза: затемнение + «дышащая» пульсирующая надпись.
- Game Over: ступенчатое красное затемнение, «наезжающий» дрожащий текст,
  счёт и подсказка R/ESC.

## Управление

| Клавиша            | Действие                      |
|--------------------|-------------------------------|
| ← → (или A/D)      | Движение влево/вправо         |
| ↓ (или S)          | Мягкое падение (soft drop, см. SOFT_DROP_INTERVAL) |
| Пробел             | Жёсткое падение (hard drop)   |
| ↑ или X            | Поворот по часовой стрелке    |
| Z                  | Поворот против часовой        |
| C                  | Удержание фигуры (hold)       |
| P                  | Пауза                         |
| R                  | Рестарт партии                |
| Esc                | Выход из игры в главное меню  |

В меню: ↑/↓ или мышь — выбор, Enter/ЛКМ — открыть, Esc — выход.

## Очки

- 1 линия — 100, 2 — 300, 3 — 500, 4 (Tetris) — 800 × (уровень + 1)
- Hard drop: +2 за клетку, каждые 10 снятых линий — новый уровень (падение быстрее)
